# TechNova — Web Basic Starter

Mở `products.html` bằng Live Server để xem trang mẫu fetch DummyJSON không cần API key.

Đọc **[HUONG_DAN_BAT_DAU.md](HUONG_DAN_BAT_DAU.md)** để xem cấu trúc file,
thứ tự học, code mẫu đã làm và checklist học sinh tự thực hiện.

Chỉ trang sản phẩm đã chuyển sang API. Các trang chi tiết, giỏ, checkout hiện vẫn
là bản thực hành tĩnh, cần nối tiếp theo hướng dẫn. Tài khoản là demo localStorage.
